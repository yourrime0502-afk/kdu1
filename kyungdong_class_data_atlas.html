EDITORIAL NOTE

작은 데이터가 보여주는
우리 반의 분위기

취미 응답에서는 음악·공연 관련 표현이 두드러지고, 게임·애니메이션·운동·창작처럼 여러 관심사가 함께 나타납니다. 거주지 응답은 수도권에 모여 있으며, 제출 시트에서는 GitHub 프로필 주소가 모두 입력된 점이 확인됩니다.

이는 15명의 자기소개를 정리한 스냅샷으로, 경동대학교 전체 학생의 성향이나 지역 분포를 대표하지 않습니다.

Source & methodology

1차 자료 — 사용자가 첨부한 「깃허브 주소 입력표 - Untitled(1).csv」의 자기소개 행 15개.

보조 자료 — 「index_경동대학교.html」의 기존 시각화 구성 및 데이터 필드 확인에 참고.

분석 범위 — 취미, 거주지 입력 여부 및 권역, GitHub 프로필 주소·개인 페이지 주소 입력 여부.

Data vs. interpretation

  • 실제 데이터: 시트에 입력된 응답 행, URL 입력 여부, 취미 원문, 거주지 텍스트.
  • 재분류·해석: 취미 주제 태깅, 광역 거주 권역 묶기, 인사이트 문장.
  • 미포함: 성별은 입력값이 비어 있거나 자유기재가 혼재해 분석에서 제외.
  • 주의: URL은 입력 여부만 집계했으며 실제 사이트 정상 작동을 검증하지 않음.
